# Bloch 定理与晶体周期性

对于周期势 U(x+d) = U(x)，波函数具有 Bloch 形式：

$$\Psi(x) = u(x)e^{ikx}$$

其中 u(x) 与晶格势 U(x) 具有相同周期性。

# 能带与固体分类

## 0 K 时电子填充能带

绝对零度时，电子按 Pauli 不相容原理从最低能级开始填充。

## 关键定义

- **导带 (Conduction Band, CB)：** T = 0 K 时具有空态的最低能带
- **价带 (Valence Band, VB)：** T = 0 K 时被电子填满的最高能带
- **能带隙 (Energy Bandgap, Eg)：** 分隔价带顶与导带底的禁带区域
- **Fermi 能级 (Ef)：** 占据概率为 1/2 的能级

## 固体分类

| 材料 | 带隙 | 电导率 |
|------|------|--------|
| 导体 | 无带隙（VB 与 CB 重叠） | 高 |
| 半导体 | 小带隙 (~1 eV) | 中等，可调控 |
| 绝缘体 | 大带隙 (>3 eV) | 极低 |
