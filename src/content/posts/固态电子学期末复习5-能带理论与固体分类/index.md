# Bloch 定理与晶体周期性

对于周期势 U(x+d) = U(x)，波函数具有 Bloch 形式：

$$\Psi(x) = u(x)e^{ikx}$$

其中 u(x) 与晶格势 U(x) 具有相同周期性。

# 能带与固体分类

## 0 K 时电子填充能带

绝对零度时，电子按 Pauli 不相容原理从最低能级开始填充。

## 关键定义

- **导带 (Conduction Band, CB)：** T = 0 K 时具有空态的最低能带
- **价带 (Valence Band, VB)：** T = 0 K 时被电子填满的最高能带
- **能带隙 (Energy Bandgap, Eg)：** 分隔价带顶与导带底的禁带区域
- **Fermi 能级 (Ef)：** 占据概率为 1/2 的能级

## 固体分类

| 材料 | 带隙 | 电导率 |
|------|------|--------|
| 导体 | 无带隙（VB 与 CB 重叠） | 高 |
| 半导体 | 小带隙 (~1 eV) | 中等，可调控 |
| 绝缘体 | 大带隙 (>3 eV) | 极低 |

# 例题与解析

## 例题 1

**例：E-k 能带结构**

某半导体具有以下 E-k 能带结构：

$$E(k) = \alpha k^2 \quad \text{(导带)}$$
$$E(k) = \beta k^2 + \gamma \quad \text{(价带)}$$

常数：α = 9.25 × 10^-40 J·m²，β = 2.2 × 10^-39 J·m²，γ = 1 × 10^10 m^-1，δ = 2.4 × 10^-19 J

绘制能带结构，求带隙能量，并估算导带底和价带顶附近电子的有效质量。

**解：**

两个函数均为抛物线。

价带顶：EVB,max = 0（在 k = 0 处）

导带底：ECB,min = δ = 1.5 eV（在 k = γ 处）

带隙：Eg = δ = 1.5 eV

有效质量：

导带底：m*_e = ℏ² / (2α)

价带顶：m*_h = ℏ² / (2|β|)

## 例题 2

**例：晶体结构 - 原胞中的原子数**

求以下晶格中每个原胞的原子数：
(a) 面心立方 (FCC)
(b) 体心立方 (BCC)
(c) 金刚石晶格

**解：**

假设每个原子为硬球，与其最近邻原子表面接触。

(a) FCC：每个原胞有 4 个原子
(b) BCC：每个原胞有 2 个原子
(c) 金刚石：每个原胞有 8 个原子

并计算每种晶格的原子堆积因子（原胞体积中被原子占据的百分比）。学习自测

1. 能带隙（Bandgap）的定义是什么？
   **答案：** 分隔价带顶与导带底的禁带区域

2. 半导体的带隙大约是多少？
   **答案：** ~1 eV

3. Fermi 能级的定义是什么？
   **答案：** 占据概率为 1/2 的能级
