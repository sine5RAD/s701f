# 电流与电流密度

电流密度 J 是单位面积流过的电流，与载流子浓度和漂移速度相关：

$$J = qnv$$

其中 q 为电荷量，n 为载流子浓度，v 为漂移速度。

# 漂移速度与电子迁移率

外加电场 E 使载流子获得漂移速度：

$$v_d = \mu E$$

电导率 σ 为：

$$\sigma = qn\mu$$

# 态密度函数 S(E)

态密度描述单位能量、单位体积内的可用电子态数。三维自由电子的态密度：

$$S(E) = C \cdot E^{1/2}$$

其中 C 为常数。

# Fermi-Dirac 分布 f(E)

温度 T 时能级 E 被占据的概率：

$$f(E) = \frac{1}{1 + e^{(E - E_f)/kT}}$$

导带中电子总数通过对 S(E)·f(E) 在能量上进行积分得到。

## 计算示例

对于 Fermi 能为 7.0 eV 的铜，0 K 时自由电子浓度可通过 S(E) = C·E^(1/2) 和 f(E)（0 K 时为阶跃函数）计算。

# 例题与解析

## 例题 1

**例 2 - Fermi 能级与电子分布**

导带电子浓度：在 0 K 时，能量范围 E1 到 E2 内的电子数为：

$$n = \int_{E1}^{E2} S(E) \cdot f(E) dE$$

Case (i): Ef = 3.5 eV，E1 和 E2 均 > Ef → n = 0

Case (ii): Ef = 5.5 eV，E1 < Ef < E2，用 Ef 替换 E2

Case (iii): Ef = 8.0 eV，E1 和 E2 均 < Ef

## 例题 2

**例：本征锗的电阻率**

(i) 纯锗 (Ge) 的带隙为 0.66 eV，300 K 时本征载流子浓度为 2.4 × 10^13 /cm³。若电子和空穴迁移率分别为 3900 cm²/(V·s) 和 1900 cm²/(V·s)，求本征电阻率（单位：Ω·cm）。

(ii) 一根直径为 1 cm、长度为 8 cm 的圆柱形纯锗棒，两端施加 2 V 电压，求流过的电流。

**解：**

(i) 本征电导率：

$$\sigma_i = n_i q (\mu_n + \mu_p)$$

电阻率 ρ = 1/σ

(ii) 电阻：R = ρL/A

电流：I = V/R（欧姆定律）

## 例题 3

**例：硅的本征能级位置**

硅在 300 K 时的本征载流子浓度 ni = 1.5 × 10^10 /cm³。

已知硅中电子有效质量与空穴有效质量之比为 1.94，带隙能量为 1.1 eV，求纯硅中 Fermi 能偏离能带中心的位置。

**解：**

本征 Fermi 能级相对于带隙中心的偏移量为：

$$E_i - E_{midgap} = \frac{3}{4}kT \ln\left(\frac{m_h^*}{m_e^*}\right)$$

代入 m_h*/m_e* = 1.94，T = 300 K 即可求得。学习自测

1. 三维态密度函数 S(E) 与能量的关系？
   **答案：** S(E) ∝ E^(1/2)

2. 电导率 σ 的公式？
   **答案：** σ = qnμ

3. 0 K 时 Fermi-Dirac 分布是什么形式？
   **答案：** 阶跃函数
