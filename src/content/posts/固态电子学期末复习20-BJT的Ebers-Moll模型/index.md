# BJT 各模式下的载流子分布

## 正向有源模式 (NPN)

- 发射结正偏
- 集电结反偏
- 电子从发射极注入基区
- 大部分电子扩散穿过薄基区到达集电极
- 一小部分在基区复合（基极电流）

# 有源模式下的电流

正向有源模式下：
- **I_E = I_C + I_B**
- **I_C = α · I_E**（共基极电流增益，α 接近 1）
- **I_C = β · I_B**（共发射极电流增益，β 通常为 50-200）

# Ebers-Moll 模型

Ebers-Moll 模型提供 BJT 在所有工作模式下的大信号方程：

- **正向电流增益 (α_F, β_F)：** 表征正向有源工作
- **反向电流增益 (α_R, β_R)：** 表征反向有源工作
- α_R 和 β_R 远小于 α_F 和 β_F

Ebers-Moll 方程描述：
- I_C 与 V_BE 和 V_BC 的关系
- I_E 与 V_BE 和 V_BC 的关系
- 四种工作区域：正向有源、截止、饱和、反向有源

# 输出特性

I_C 与 V_CE 的特性曲线（NPN 情况）显示：
- **正向有源区：** I_C 近似恒定（对 V_CE 饱和）
- **饱和区：** 两个结均正偏，V_CE 很小
- **截止区：** 两个结均反偏，I_C 近似为零

# 基区宽度调制：Early 效应

Early 效应描述有效基区宽度随 V_CE 增大而减小的现象：
- V_CE 增大使集电结耗尽区展宽
- 这减小了中性基区宽度
- 基极电流减小，导致 I_C 随 V_CE 略有增大
- 结果：输出特性在有源区具有有限斜率，外推线汇聚于**Early 电压 V_A**
