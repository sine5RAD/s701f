# PN 结静电特性

## 电场分布

耗尽层中的电场随位置变化：
- P 侧：电场由电离受主电荷决定
- N 侧：电场由电离施主电荷决定

## 电势（接触电势）

耗尽层上的电势分布：
- P 侧：电势随距结距离变化
- N 侧：电势随距结距离变化
- 内建电势 V_bi 为耗尽层上的总电势差

# 计算示例

求理想硅 PN 结在 300 K 时的接触电势、耗尽层宽度和最大电场。

**解：**
- **接触电势：** V_bi = (kT/q) · ln(ND·NA/nᵢ²)
- **耗尽层宽度：** W = P 侧耗尽宽度 + N 侧耗尽宽度
- **N 侧耗尽层延伸：** 由掺杂浓度决定
- **最大电场：** 位于冶金结面处

# 正偏

外加正偏压时（P 正 N 负）：
- 耗尽层宽度减小
- 大电流可通过结
- 能垒降低
