# 双极型晶体管 (BJT)

BJT 是另一种晶体管类型，具有以下特点：
- 同时利用电子和空穴电流（故称"双极型"）
- 与 MOSFET 一样是三端器件
- 两端之间的电压控制第三端中流过的电流
- 可用于放大（模拟电子学）或开关（数字电子学）

# NPN BJT 结构

NPN BJT 由以下部分组成：
- **发射极 (E)：** N 型区域，重掺杂
- **基区 (B)：** P 型区域，薄且轻掺杂
- **集电极 (C)：** N 型区域

结构：N 型发射极 - P 型基区 - N 型集电极（三明治结构）

## 理想化结构

- 发射极和集电极为 N 型区域
- 基区为两者之间的薄 P 型区域
- 三个区域均制作金属接触

## 实际结构

实际 BJT 制造中：
- 发射极和集电极位于基区两侧
- 基区极薄以利于载流子输运
- 各区域掺杂浓度不同以优化性能

# 学习自测

1. BJT 为何称为[双极型]？
   **答案：** 同时利用电子和空穴电流

2. NPN BJT 中基区是什么类型？
   **答案：** P 型

3. BJT 是什么控制器件？
   **答案：** 电流控制器件（基极电流控制集电极电流）
