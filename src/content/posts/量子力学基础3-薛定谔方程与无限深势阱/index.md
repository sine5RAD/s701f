# Schrödinger 波动方程

## 一维自由粒子 (U = 0)

对于势能为零的自由粒子，一维 Schrödinger 方程描述平面波解。

## 无限深势阱

被限制在宽度为 d 的无限深势阱中的粒子只能占据离散的能级：

$$E_n = \frac{n^2\pi^2\hbar^2}{2md^2}$$

其中 n 为整数量子数 (n = 1, 2, 3, ...)。

阱内波函数 (0 ≤ x ≤ d, U(x) = 0) 需满足边界条件：
- ψ(0) = 0
- ψ(d) = 0

## E-k 色散图

能量-波矢 (E-k) 色散图展示了周期势阱中粒子的能量与波矢关系，对理解晶体中能带形成至关重要。

## 无限势阱求解示例

求解无限深势阱中粒子的 Schrödinger 方程：
- 在 0 ≤ x ≤ d 区域，U(x) = 0
- 边界条件：波函数在阱壁处为零
- 解产生驻波模式
- 能量量子化：E 与 n² 成正比
